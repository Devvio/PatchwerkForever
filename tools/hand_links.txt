# Ways the game files do not describe: lifts, and anything else that has to be told.
# links.py reads this file and adds each line as a link (both directions).
#
#   map   from: X  Y    to: X  Y    seconds   name
#   map   from: X  Y    to: X  Y    seconds   oneway   name      (only from the first place to the second: a drop)
#
# map       0 Eastern Kingdoms, 1 Kalimdor
# X, Y      world coordinates of where the character stands on the ground just before
#           stepping on, and just after stepping off.
#
# The easy way: mark both ends in game with the macro in marks.py, /reload, and run
#     python marks.py
# which checks the marks against our ground and writes the lines at the end of this file.
# By hand: /run print(UnitPosition("player")) prints X, Y, height, map.
# seconds   how long the ride takes, with an average wait.
#
# A lift that rides in a tower of its own (the Great Lift, Freewind Post's) is found from the tower's
# model by lifts.py, which writes its lines here too: python lifts.py write
#

#   does not know. Thunder Bluff's four are below.
#

#   1   -1234.5 100.0    -1260.0 95.0    25   Thunder Bluff, north lift
